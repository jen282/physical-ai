[ ] 균일·민무늬 [v] 규칙적 패턴(헤어라인, 직조, 격자) [ ] 불규칙 텍스처(주물, 샌딩) [v] 인쇄/문자 있음
📝 배선 패턴과 비아홀이 규칙적으로 반복되고, 흰색 실크스크린 문자(부품 번호)가 인쇄되어 있음.

### 1-4. 색상

[ ] 단색(밝음) [ ] 단색(어두움/검정) [v] 다색 [v] 제품마다 색상 편차 있음
📝 녹색 솔더마스크, 은색 납땜, 검정/갈색 부품, 흰색 실크가 섞여 있고, 기판 공급사 로트별로 녹색 톤이 다름.

### 1-5. 형상

[ ] 평면(2D) [ ] 곡면/원통형 [v] 복잡한 3D 형상(단차, 홈) [ ] 유연체(형태 변함)
📝 0402 칩부품(높이 약 0.35mm)부터 전해 콘덴서(높이 약 8mm)까지 부품 높이 차이가 큼.

[ ] ~10mm [ ] 10~50mm [v] 50~200mm [ ] 200mm~1m [ ] 1m 이상
