02 · 전처리

많이 고치지 않고, 처음부터 바르게

좋은 로봇 정책은 화려한 데이터 보정이 아니라 일관된 데이터에서 나옵니다. TeachArm은 수집 단계에서 카메라, 제어 주기, 좌표계를 고정해 보정할 필요 자체를 줄이고, 꼭 필요한 처리만 정해진 순서대로 적용합니다.

PRINCIPLES

설계 원칙

P1

수집 조건을 먼저 고정합니다

카메라 영상과 관절 데이터를 하나의 시계, 같은 30Hz 주기로 기록하고 노출·화이트밸런스·초점을 수동으로 고정합니다. 나중에 고치는 것보다 처음부터 맞추는 것이 확실하기 때문입니다.

P2

명백히 나쁜 데이터만 거릅니다

적은 시연으로 학습하는 만큼 시연 하나하나가 소중합니다. 실패하거나 손상된 기록만 제외하고, 다시 집어서 성공한 시연처럼 회복 동작이 담긴 데이터는 남겨 로봇이 실수에서 회복하는 법을 배우게 합니다.

P3

학습과 실행 환경을 일치시킵니다

해상도, 색상 형식, 정규화 통계, 로봇 캘리브레이션까지 학습할 때와 실제 가동할 때 똑같이 적용합니다. "학습은 잘 됐는데 현장에서는 안 움직이는" 문제는 대부분 여기서 생깁니다.

PIPELINE

처리 단계

  1. 0

    원본 무결성 점검

    시연마다 영상 프레임 수와 관절 기록 수가 정확히 일치하는지, 비어 있거나 범위를 벗어난 값이 없는지, 영상이 정상적으로 열리는지 확인합니다.

    손상된 기록이 이후의 모든 통계와 선별 기준을 오염시키기 전에 가장 먼저 걸러냅니다.

  2. 1

    동기화 검증

    실제 기록 간격과 카메라 지연을 측정합니다. 지연이 시연마다 일정하다면 데이터를 억지로 옮기지 않습니다. 실제 가동 때도 같은 지연이 존재하므로, 그대로 두는 편이 실행 환경과 일치합니다.

    동기화 문제를 모른 채 데이터를 다듬으면 문제가 해결되는 것이 아니라 감춰질 뿐입니다.

  3. 2

    시연 선별

    실패한 시연, 길이가 비정상적인 시연, 프레임 손실이 많은 시연을 제외합니다. 영상과 관절 데이터 중 하나라도 문제가 있으면 해당 시연 전체를 함께 제외합니다.

    정규화 통계를 계산하기 전에 이상 데이터를 빼야 분포가 왜곡되지 않습니다.

  4. 3

    궤적 정제

    서보 통신 오류로 생기는 순간적인 값 튐만 골라 제거하고 정상 신호는 건드리지 않습니다. 부드럽게 다듬는 스무딩은 실제 떨림이 확인될 때만 적용하며, 동작 전후의 정지 구간은 잘라내되 움직임 직전의 짧은 여유는 남깁니다.

    튐을 먼저 제거하지 않고 스무딩하면 오류 하나가 주변 프레임으로 번집니다.

  5. 4

    작업 단계 라벨링분석용

    그리퍼의 위치와 전류 변화로 집기·이송·놓기 구간을 자동으로 나눕니다. 그리퍼가 닫히다 멈추고 전류가 급상승하는 순간이 곧 파지 성공 시점입니다. 이 라벨은 학습 입력이 아니라 실패가 어느 단계에서 일어나는지 진단하는 데 씁니다.

  6. 5

    영상 변환

    영상 해상도를 작업에 필요한 수준으로 줄이고 색상 형식을 통일합니다. 연산량이 약 4분의 1로 줄어 소형 컴퓨터에서도 실시간 추론이 가능해집니다. 압축으로 인한 학습·실행 간 화질 차이를 줄이기 위해 고화질로 인코딩합니다.

    증강보다 먼저 크기를 줄여야 연산 비용이 줄고, 잘라내는 비율의 의미도 일정하게 유지됩니다.

  7. 6

    정규화

    관절별로 값의 평균과 분산을 맞춥니다. 통계는 선별과 정제가 끝난 학습 데이터로만 다시 계산하며, 같은 통계와 같은 캘리브레이션 파일을 실제 가동 때도 그대로 사용합니다.

    선별보다 먼저 정규화하면 제외된 데이터의 값이 통계에 남습니다.

  8. 7

    데이터 증강학습 중 적용

    상단 카메라에는 미세한 위치 이동과 색감 변화를, 손목 카메라에는 색감 변화와 작은 회전만 적용합니다. 그리퍼와 물체의 상대 위치가 핵심인 손목 시점은 형태 변형을 약하게 유지합니다.

    증강은 화면 속 위치 변화를 흉내 낼 뿐, 다른 위치로 팔을 뻗는 동작 자체를 만들어내지는 못합니다. 그래서 TeachArm은 작업 영역을 구역으로 나눠 위치별 시연을 고르게 수집합니다.

  9. 8

    데이터 분할

    프레임이 아닌 시연 단위로, 물체 위치 구역이 고르게 섞이도록 학습·검증 세트를 나눕니다. 처리 전 원본 데이터는 항상 별도로 보관합니다.

BY DESIGN

하지 않는 것도 설계입니다

처리를 더한다고 데이터가 좋아지지는 않습니다. TeachArm이 의도적으로 하지 않는 처리들입니다.

✕

그리퍼 신호는 다듬지 않습니다

쥐는 순간의 빠른 닫힘이 흐려지면 로봇이 "천천히 쥐는" 동작을 배워 물체를 놓칩니다.

✕

지령값과 실제값의 차이를 오류로 보지 않습니다

물체를 쥐면 로봇의 그리퍼는 물체에 막혀 지령보다 덜 닫힙니다. 이 차이가 곧 "얼마나 세게 쥐는가"에 대한 정보입니다.

✕

영상을 좌우로 뒤집지 않습니다

좌우 반전은 흔한 증강 기법이지만, 관절 좌표와 영상 속 공간 관계를 깨뜨립니다.

✕

렌즈 왜곡 보정과 노이즈 제거를 하지 않습니다

카메라가 단단히 고정되어 있다면 일관성만으로 충분합니다. 이런 처리는 실제 가동 중 매 프레임마다 반복해야 하는 부담만 늘립니다.

DATA FLOW

두 개의 흐름, 세 개의 접점

영상 데이터와 로봇 데이터는 각자의 경로로 처리되지만, 세 지점에서 반드시 하나로 맞춰집니다.

1

같은 시각으로 묶기: 프레임 번호를 공통 기준으로 영상과 관절 데이터가 같은 순간을 가리키는지 확인합니다.

2

함께 판정하기: 품질은 각자 측정하지만 제외 여부는 시연 단위로 함께 결정합니다.

3

같은 구간 자르기: 로봇의 움직임으로 계산한 자르기 구간을 두 카메라 영상에도 똑같이 적용합니다.

VERIFICATION

처리 결과는 숫자와 그림으로 확인합니다

동기화

기록 간격 분포와 시연별 지연을 확인합니다. 지연이 시연마다 일정하면 정상입니다.

궤적 품질

모든 시연의 궤적을 겹쳐 그려 이상한 시연을 한눈에 찾고, 정제 전후 차이가 0.5° 이하인지 확인합니다. 이보다 크면 필터가 신호를 깎고 있다는 뜻입니다.

영상 품질

시연별 선명도와 밝기 분포를 비교합니다. 들쑥날쑥하다면 카메라 자동 설정이 켜져 있다는 신호입니다.

데이터 분포

물체 초기 위치를 작업 영역 지도에 표시합니다. 빈 구역이 곧 추가 수집 대상입니다.

flag

가장 중요한 지표는 실제 로봇의 성공률입니다. TeachArm은 학습한 위치와 처음 보는 위치를 나눠 테스트하고, 집기·이송·놓기 중 어느 단계에서 실패했는지까지 기록합니다.

보조 모듈 · 객체 탐지

로봇을 움직이지 않고, 결과를 확인합니다

TeachArm의 동작 정책은 영상에서 곧바로 동작을 배우므로 물체 탐지 결과가 필요하지 않습니다. 객체 탐지기는 제어 루프 밖에서, 녹화된 영상을 노트북에서 사후에 일괄 처리하는 보조 도구입니다. 실시간일 필요가 없어 로봇 컴퓨터에 올리거나 지연을 검증할 비용도 들지 않습니다.

ROLE

탐지기가 하는 네 가지 일

모든 결과는 보조 지표로만 기록하며, 실험의 공식 성공·실패 판정은 운영자가 내립니다.

fact_check

데이터 점검

시연 시작 시 큐브가 화면에 보이는지, 증강 후 큐브가 잘려 나가지 않았는지 확인합니다.

my_location

인식 실패 판정 보조

그리퍼가 다가간 지점과 탐지된 큐브 중심의 거리를 계산합니다. 5cm 이상 벗어나면 인식 실패로 기록합니다.

check_circle

성공 판정 보조

마지막 프레임에서 큐브가 미리 지정한 접시 영역 안에 놓였는지 확인합니다.

grid_on

위치 교차 확인

큐브 위치는 그리드 번호와 로봇 관절값으로 기록하고, 탐지 결과는 그 기록을 한 번 더 검산하는 데 씁니다.

DESIGN

작게, 하나만, 자동으로

D1

가장 작은 모델 하나

고정 카메라, 고정 배경에 물체 한 종류뿐인 단순한 장면이라 YOLO26 Nano 단일 모델을 사용합니다. 큰 모델은 적은 데이터에서 과적합 위험만 키웁니다. 작은 물체 학습에 유리하고 후처리가 단순하다는 점도 선택 이유입니다.

D2

찾는 것은 큐브 하나

클래스는 큐브 하나, 입력은 상단 카메라 하나입니다. 위치가 고정된 접시는 좌표를 설정 파일에 적어 두고, 그리퍼 위치는 관절값으로 계산합니다. 탐지할 대상을 줄이면 라벨링 비용도 함께 줄어듭니다.

D3

라벨은 기계가, 검수는 사람이

시연 영상에서 단계별로 고르게 뽑은 약 400장에 색상 기반으로 박스를 자동 생성하고, 사람은 검수만 합니다. 학습·검증 세트는 프레임이 아닌 시연 단위로 나눠 지표가 부풀려지는 것을 막습니다.

TRAINING

학습은 한 번에, 짧게

사전학습 가중치에서 시작해 전체 레이어를 한 단계로 파인튜닝합니다. 재현하기 쉬운 단순한 절차가 이 규모에서는 가장 큰 장점입니다.

입력 해상도
640px, 원본 비율 유지. 약 30px 크기의 작은 큐브를 선명하게 보존합니다.
증강
카메라와 물체 크기가 고정이라 기본값보다 약하게 적용합니다. 탐지 라벨은 영상과 함께 뒤집히므로, 동작 정책과 달리 좌우 반전을 사용합니다.
학습 길이
최대 80에포크. 20에포크 동안 개선이 없으면 조기 종료합니다.
최적화
AdamW, 학습률 1e-3에서 코사인 곡선으로 감소. 3에포크 워밍업으로 사전학습 가중치를 보호합니다.
하드웨어
클라우드 T4 GPU 1장, 혼합 정밀도와 메모리 캐시로 약 15~20분이면 끝납니다.
데이터 판단
데이터의 25%·50%·100%로 학습해 비교합니다. 성능이 더 오르지 않으면 라벨을 늘리지 않습니다.
ACCEPTANCE

합격 기준은 두 가지뿐입니다

탐지기의 출력은 결국 "책상 위 큐브 좌표"로 쓰입니다. 그래서 박스 지표 대신 실제 쓰임과 직결된 지표로 판단합니다. 테스트에는 실제 평가 시도의 첫 프레임을 사용해 추가 수집 없이 검증합니다.

위치 오차 (상위 95%)
≤ 1.5cm

탐지된 박스 중심을 책상 좌표로 변환해 그리드 정답과 비교합니다. 인식 실패 기준인 5cm보다 3배 이상 여유가 있어 판정 오류를 무시할 수 있습니다.

재현율 (Recall)
≥ 0.95
