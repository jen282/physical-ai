PROBLEM

초당 10개 부품, 사람의 눈으로는 놓칩니다

라인에는 부품이 100ms 간격으로 지나갑니다. 기존 검사 방식은 속도, 일관성, 보안 중 어느 하나에서 한계가 있습니다.

[01 :: MANUAL]

육안 검사

속도 한계가 있고 검사원마다 기준이 다릅니다. 야간·장시간 근무에서는 피로로 정확도가 떨어지며 24시간 인력 운영 비용이 듭니다.

검출률 85~90% 수준 (가정)
[02 :: RULE-BASED]

규칙 기반 비전 검사

조명이나 표면 질감이 조금만 달라져도 오검출이 늘고, 신제품마다 규칙을 사람이 다시 만들어야 합니다.

신제품마다 재설정 필요
[03 :: CLOUD]

클라우드 AI 검사

판정 50ms를 매번 보장하기 어렵고 외부 인터넷이 막힌 공장에서는 구성할 수 없습니다. 하루 2TB 업로드와 영업비밀 유출 위험도 부담입니다.

HOW IT WORKS

촬영부터 배출까지, 6단계

모든 과정이 공장 내부망 안에서 완결됩니다.

01

설치

카메라 4대와 LED 조명을 컨베이어 위에 고정하고, 라인 옆에 산업용 GPU PC를 설치합니다. 센서·엔코더·배출기를 PC의 I/O에 연결합니다.

02

데이터 수집

부품 감지 센서 신호에 맞춰 카메라가 정확한 순간에 촬영합니다(스트로브 조명 동기). 영상은 GigE 케이블로 GPU PC에 전달됩니다.

03

분석

GPU PC가 영상을 전처리한 뒤 약 100MB 모델로 추론해 정상/불량 여부, 불량 종류, 불량 위치를 계산합니다.

04

판정

불량 점수가 임계값을 넘으면 NG, 아니면 OK. 판정 결과·불량 이미지·신뢰도·시각이 한 건의 기록으로 남습니다.

05

제어

NG 판정 시 엔코더 위치 기준으로 부품이 배출기 앞에 도착하는 순간 PLC에 신호를 보내 불량 상자로 배출합니다. 연속 불량이면 경광등과 알림이 작동합니다.

06

확인·개선

대시보드에서 불량률 추이와 불량 이미지를 확인합니다. 오판정은 정정 표시하면 다음 재학습에 반영됩니다.
