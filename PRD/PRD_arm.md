# PRD: TeachArm — 시연으로 가르치는 모방학습 로봇팔

| 항목             | 내용                                                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 제품명           | TeachArm (가칭)                                                                                                           |
| 한 줄 정의       | 사람이 로봇팔을 원격조작해 수십 번 시연하면, 로봇이 그 시연으로 모방학습 정책을 학습해 같은 작업을 스스로 수행하는 시스템 |
| 주요 입력 데이터 | 상단 카메라·손목 카메라 영상(RGB), 리더 팔 관절값(6축) 또는 MediaPipe 손 랜드마크, 팔로워 팔 관절 상태                    |
| 주요 출력(행동)  | 팔로워 팔 6축 관절 목표값(Action Chunk)을 연속 출력하여 큐브를 집어 접시 위에 놓음, 시도 결과와 실패 유형 기록            |
| MVP 작업         | 책상 위 20×20cm 영역 안 임의 위치의 큐브 1개를 집어 고정된 접시 위에 놓기                                                 |
| MVP 성공 기준    | 시연 50개로 학습한 정책이 학습 위치 범위 안에서 성공률 60% 이상 (1차 실험 후 조정)                                        |

---

## 1. 문제 정의 (Problem Statement)

### 1.1 현재 문제

소규모 제조, 연구실 자동화, 물류 키팅 현장에는 "부품을 집어서 정해진 곳에 놓는" 단순 반복 작업이 많습니다. 그러나 로봇 도입은 대부분 대량 생산 라인에 한정됩니다. 그 이유는 로봇 하드웨어 가격보다 **작업을 가르치는 비용(프로그래밍·티칭)**이 더 크기 때문입니다. 물체 위치가 매번 바뀌거나 작업이 자주 변경되는 현장에서는 이 비용이 반복해서 발생합니다.

### 1.2 기존 방식의 한계

| 기존 방식                            | 한계                                                                                                                                  |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| 티치 펜던트 좌표 티칭                | 물체가 정확히 같은 위치에 있어야 동작하며, 위치가 1~2cm만 달라져도 실패함. 위치 변동에 대응하려면 지그나 피더 같은 추가 설비가 필요함 |
| 규칙 기반 비전 + 모션 플래닝         | 카메라 캘리브레이션, 물체 검출, 파지점 계산, 경로 계획을 각각 엔지니어가 설계해야 함. 작업이 바뀔 때마다 재개발 필요                  |
| 외부 SI(시스템 통합) 업체 의뢰       | 셀 1개 구축에 수천만 원, 작업 변경 1회에 수백만 원과 수 주의 리드타임 발생 (가정)                                                     |
| 직접 교시(Direct Teaching, 협동로봇) | 궤적을 그대로 재생하는 방식이라 위치 변동에 대응하지 못함                                                                             |

### 1.3 핵심 가치

1. **프로그래밍 없는 작업 교시:** 비전문가도 리더 팔을 움직여 시연을 보여주는 것만으로 작업을 가르칠 수 있습니다.
2. **위치 변동 대응:** 카메라 영상을 보고 매 순간 행동을 결정하는 폐루프 정책이므로, 정해진 영역 안에서 물체 위치가 바뀌어도 작업을 수행합니다.
3. **저비용 검증:** 오픈소스 하드웨어(SO-101)와 소프트웨어(LeRobot)로 셀 1개를 수십만 원 단위 하드웨어로 구성하여, 도입 전 기술 타당성을 낮은 리스크로 검증합니다.
4. **정량 근거 확보:** 데이터 양, 일반화, 원격조작 방식, 엣지 추론의 4개 실험으로 "몇 개의 시연이면 충분한가", "저가 엣지 장치로 돌아가는가"에 대한 수치 근거를 만듭니다.

### 1.4 AI가 필요한 이유

큐브 위치가 매번 바뀌면 "큐브가 어디에 있는가 → 어떤 자세로 접근할 것인가 → 언제 그리퍼를 닫을 것인가"를 매번 새로 결정해야 합니다. 이를 규칙으로 작성하려면 비전, 역기구학, 경로 계획을 모두 직접 설계해야 합니다. 모방학습(ACT)은 영상과 관절 상태를 입력받아 다음 행동을 직접 출력하는 하나의 신경망으로 이 과정 전체를 시연 데이터에서 학습합니다. 작업을 바꿀 때도 코드를 고치지 않고 시연 데이터를 새로 수집해 재학습하면 됩니다.

## 2. 사용자 시나리오 (User Scenario)

**주요 사용자:** 시연자(작업을 가르치는 현장 작업자 또는 연구자), 운영자(학습·평가를 관리하는 엔지니어)

### 1단계 — 설치

운영자가 SO-101 리더 팔과 팔로워 팔을 책상에 고정하고 각 팔의 서보 버스 컨트롤러를 USB로 노트북에 연결합니다. 상단 카메라는 작업 영역 전체가 보이도록 약 60cm 높이에 고정하고, 손목 카메라는 팔로워 팔의 그리퍼 근처에 장착합니다. LeRobot 캘리브레이션 스크립트로 두 팔의 관절 영점과 범위를 맞추고, 책상 위에 20×20cm 작업 영역과 접시 위치를 테이프로 표시합니다. 평가 재현성을 위해 영역 안에 5×4 그리드로 평가 위치 20개를 미리 정의하고, 영역 경계 바깥 5~10cm 구간에 범위 밖 평가 위치 20개를 정의합니다. 설치부터 캘리브레이션까지 반나절 이내 완료를 목표로 합니다.

### 2단계 — 데이터 수집

시연자가 리더 팔을 손으로 움직이면 팔로워 팔이 실시간으로 따라 움직입니다(30Hz). 시연자는 매 에피소드마다 큐브를 영역 내 임의 위치에 놓고, 집기부터 놓기까지 한 번에 시연합니다. 시스템은 상단·손목 카메라 영상(640×480, 30fps), 팔로워 관절 상태(6축), 리더 관절값(행동 레이블)을 동기화하여 LeRobot 데이터셋 형식(Parquet + MP4)으로 저장합니다. 비교 실험용으로 MediaPipe Hands 손 추적 모드에서도 같은 방식으로 수집합니다. 수집이 끝나면 품질 검사 스크립트가 프레임 누락, 비정상 관절값, 실패한 시연을 자동 표시하고 시연자가 폐기 여부를 결정합니다.

### 3단계 — AI 분석(학습)

운영자는 먼저 MuJoCo 시뮬레이션 환경에서 ACT 학습·평가 파이프라인이 정상 동작하는지 확인합니다(시뮬 성공률로 하이퍼파라미터와 코드 버그를 사전 검증). 이후 실제 데이터셋을 Colab GPU에서 학습합니다. 실험 ①을 위해 시연 10/25/50개 부분 데이터셋으로 각각 모델을 학습하고, 체크포인트와 학습 곡선은 Weights & Biases와 Hugging Face Hub에 버전별로 저장합니다.

### 4단계 — 판단 결과 생성

실행 시 정책은 매 추론마다 두 카메라 영상과 현재 관절 상태를 입력받아 향후 수십 스텝 분량의 관절 목표값 묶음(Action Chunk)을 출력합니다. 연속 추론 결과는 Temporal Ensembling으로 가중 평균하여 동작을 부드럽게 만듭니다. 실험 ④에서는 같은 정책을 노트북과 Raspberry Pi 5에서 각각 실행해 추론 지연을 측정합니다.

### 5단계 — 장치 제어

정책이 출력한 관절 목표값은 30Hz 제어 루프를 통해 팔로워 팔 서보로 전송됩니다. 안전을 위해 관절 각도 제한, 1스텝당 최대 변화량 제한, 그리퍼 토크 제한을 적용하고, 작업 영역을 벗어나는 명령은 차단합니다. 시도 시간이 30초를 넘으면 자동으로 중단하고 홈 자세로 복귀합니다. 물리적 비상정지 스위치로 언제든 서보 전원을 차단할 수 있습니다.

### 6단계 — 결과 확인 및 후속 조치

운영자는 각 시도가 끝날 때마다 평가 화면에서 성공/실패와 실패 유형(인식·접근·파지·놓기)을 기록하고, 시스템은 시도 영상과 지연 로그를 함께 저장합니다. 대시보드에서는 실험 조건별 성공률, 위치별 성공 히트맵, 실패 유형 분포, 추론 지연 분포를 확인합니다. 특정 위치나 실패 유형이 반복되면 해당 조건의 시연을 추가 수집해 재학습하고, 결과는 실험 리포트로 정리합니다.

## 3. 성공 지표 (Success Metrics)

### 3.1 실패 유형 정의 (평가 공통 기준)

| 실패 유형 | 정의                                                                                       |
| --------- | ------------------------------------------------------------------------------------------ |
| 인식 실패 | 팔이 큐브가 아닌 엉뚱한 위치로 이동함 (큐브 중심에서 5cm 이상 벗어난 위치로 접근)          |
| 접근 실패 | 큐브 방향으로는 이동하나 파지 가능한 자세에 도달하지 못함 (충돌, 높이 오차, 큐브를 밀어냄) |
| 파지 실패 | 그리퍼를 닫았으나 큐브를 들어 올리지 못하거나 이송 중 떨어뜨림                             |
| 놓기 실패 | 큐브를 이송했으나 접시 밖에 놓거나 놓은 뒤 접시에서 떨어짐                                 |
| 성공      | 30초 이내에 큐브가 접시 위에 정지 상태로 놓임                                              |

### 3.2 핵심 실험 KPI

| 실험            | 비교 조건              | 지표                                          | 목표 (가정, 1차 실험 후 조정)                                               |
| --------------- | ---------------------- | --------------------------------------------- | --------------------------------------------------------------------------- |
| ① 데이터 양     | 시연 10 / 25 / 50개    | 조건당 20회 시도 성공률                       | 50개 ≥ 60% (MVP 기준), 시연 수 증가에 따라 성공률이 단조 증가하는 경향 확인 |
| ② 일반화        | 학습 위치 범위 안 / 밖 | 성공률, 실패 유형 분포                        | 범위 안 ≥ 60%, 범위 밖 성능 하락 폭과 주된 실패 유형을 정량 보고            |
| ③ 원격조작 방식 | 리더 팔 / 손 추적      | 시연 1회 완료 시간, 동작 떨림, 학습 후 성공률 | 리더 팔 시연 완료 시간 ≤ 15초, 손 추적 대비 떨림 지표 50% 이상 낮음         |
| ④ 엣지 추론     | 노트북 / Pi 5          | 추론 지연 p50/p95, 실행 성공률                | 노트북 p95 ≤ 50ms, Pi 5 p95 ≤ 300ms, Pi 5 성공률이 노트북 대비 10%p 이내    |

동작 떨림은 리더 팔 또는 손 추적으로 생성한 관절 명령의 저크(jerk, 가속도 변화율) RMS와 5Hz 이상 고주파 성분의 에너지 비율로 측정합니다. 성공률 비교는 시도 횟수가 조건당 20회로 적으므로 95% 신뢰구간(Wilson)을 함께 보고합니다.

## 4. 기술 스택 (Technology Stack)

| 구성              | 사용 기술                                                                                                  | 선정 이유                                                                                                                                                              |
| ----------------- | ---------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 로봇 하드웨어     | SO-101 리더·팔로워 팔 (Feetech STS3215 서보 6축, 3D 프린팅 구조)                                           | LeRobot이 공식 지원하는 오픈소스 팔로 드라이버와 캘리브레이션 도구가 이미 제공됩니다. 리더 팔과 팔로워 팔의 구조가 같아 관절 대 관절 매핑만으로 원격조작이 가능합니다. |
| 카메라            | USB UVC 카메라 2대 (상단 고정 1대, 손목 장착 1대, 640×480 30fps)                                           | 상단 카메라는 큐브와 접시의 전역 위치를, 손목 카메라는 파지 직전의 정밀한 상대 위치를 제공합니다. ACT 원 논문의 다중 시점 구성과 같은 방식입니다.                      |
| 센서              | 서보 내장 12bit 자기식 엔코더 (관절 위치), 서보 전류값 (그리퍼 파지 판단 보조)                             | 별도 센서 없이 관절 상태를 얻을 수 있고, 전류값으로 파지 여부를 간접 확인해 파지 실패 자동 판정에 활용합니다.                                                          |
| MCU / 구동 제어   | 서보 버스 컨트롤러 보드 (USB–TTL 시리얼, 1Mbps)                                                            | SO-101 표준 구성입니다. 6축 서보를 하나의 버스로 제어하므로 배선이 단순하고 30Hz 동기 읽기·쓰기가 가능합니다.                                                          |
| 원격조작 (기본)   | 리더 팔 관절값 → 팔로워 팔 직접 매핑                                                                       | 지연이 거의 없고 사람이 물리적 감각으로 자세를 잡을 수 있어 시연 품질이 높습니다.                                                                                      |
| 원격조작 (비교)   | MediaPipe Hands (21개 손 랜드마크) + 역기구학 (ikpy)                                                       | 별도 하드웨어 없이 웹캠만으로 원격조작이 가능한지 검증하기 위한 비교군입니다.                                                                                          |

## 6. ROI 분석 (Business Value)

### 6.1 산정 전제

MVP(성공률 60%)는 사람이 계속 지켜봐야 하는 수준이므로, MVP 자체로는 현장 비용 절감이 발생하지 않습니다. 따라서 ROI는 **MVP 검증 후 확장 목표(성공률 90% 이상)를 달성해, 경량 부품 키팅 공정의 Pick & Place 셀 3개에 적용하는 경우**를 기준으로 산정하고, MVP 단계는 별도 시나리오로 표시합니다. (가정)

- 대상 공정: 소형 부품(100g 이하)을 트레이에서 집어 키트 박스에 담는 단순 반복 작업 (가정)
- 작업자 월 인건비: 3,300,000원 (4대보험 포함, 가정)
- 셀 1개당 해당 작업자 근무시간의 30%를 대체 (가정)
- 기존 대안: 작업 변경 시 외부 SI 재프로그래밍 1회당 2,500,000원 (가정)
- LeRobot, PyTorch, MuJoCo, MediaPipe는 오픈소스 라이선스로 비용 없음

### 6.7 최종 판정

> ### ⚠️ 조건부 투자 타당 (Stage-Gate Go)
>
> **1단계 (MVP, 현재 범위):** 투자 규모가 약 2,100만 원으로 작고 그중 하드웨어는 약 600만 원 수준이므로, 실패하더라도 손실이 제한적인 기술 검증 투자로서 타당합니다. 이 단계의 가치는 비용 절감이 아니라 "시연 몇 개로, 어느 범위까지, 어떤 장치에서 동작하는가"에 대한 정량 근거(실험 ①~④)를 확보하는 데 있습니다.
>
> **2단계 (현장 파일럿) 진입 조건:**
>
> 1. 시연 50개 기준 학습 범위 안 성공률 60% 이상 달성 (MVP 기준)
> 2. 시연 수 증가에 따른 성공률 상승 추세 확인 → 추가 시연으로 90% 도달 가능성 근거 확보
> 3. Pi 5 추론 시 성공률 하락 10%p 이내 → 셀당 저가 엣지 구성 가능 확인
>
> 위 조건을 충족하고 확장 단계에서 성공률 90% 이상을 달성하면, 기준 시나리오에서 연간 ROI 238.7%, 투자 회수기간 약 5개월로 투자 매력도가 매우 높습니다. 성공률 85%의 보수적 시나리오에서도 회수기간이 약 13.7개월로 일반적인 설비 투자 기준(24개월 이내)을 충족합니다.
